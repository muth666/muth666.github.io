Privacy Policy

Home Assistant Backup is a private application used exclusively by its owner. It is not offered to anyone else.

What data is accessed

The application uses the Google Drive scope drive.file. It can only see and manage the files it has created itself, which are the Home Assistant backup files and the folder that holds them. It cannot access any other files in Google Drive.

How the data is used

Backups are uploaded, listed, downloaded for restore and deleted according to the owner's backup settings. No other processing takes place.

Sharing and storage

No data is shared with, sold to or transferred to any third party. Access tokens are stored only on the owner's local Home Assistant system.

Revoking access

Access can be revoked at any time in the Google Account under Security → Third-party apps with account access.
